Proyecto final · prototipos web

Cuatro sistemas de gestión, cuatro oficios

Prototipos funcionales que se usan directamente en el navegador, en computador o celular. Cada uno guarda sus datos en el mismo dispositivo, así que puedes probar todo sin miedo: hay un botón para restablecer los datos de ejemplo.

Cómo están hechos: HTML5, CSS3 con Tailwind CSS (vía CDN) y JavaScript puro, sin servidor ni base de datos. Los datos se guardan en el navegador con localStorage.

Son prototipos para demostrar funcionalidades: las boletas y facturas no tienen validez tributaria y el newsletter simula el envío.
